# Vöner Ticket Collector

An unofficial Android fan project inspired by Vöner.

Vöner Ticket Collector is a small passion project created for fun. The app is designed to make collecting and managing Vöner ticket numbers simple and convenient.

## Features

- **Ticket Collection:** Collect and manage your ticket numbers in one place.
- **Ticket Overview:** Keep track of your collected numbers.
- **Simple Interface:** A clean and easy-to-use Android experience.

## Download

Download the latest Android APK from the [Releases page](https://github.com/fixspix-cloud/Voener-Ticket-Collector/releases/latest).

### Installation

1. Download the latest APK.
2. Open the downloaded file on your Android device.
3. Allow installation from this source if prompted.
4. Install and launch the app.
